## 2026-03-10 自我提升 - Godot RPG 架构思考

- **状态机模式**: 游戏实体应使用 StateMachine 管理不同状态（Idle, Run, Attack, Hurt等），每个状态独立类
- **资源加载模式**: 使用 preload() 预加载场景和资源，避免运行时卡顿
- **信号通信**: Godot 的 Signal 是解耦利器，建议用于：玩家受伤通知UI、任务状态变化、物品收集事件
- **数据驱动设计**: 商店/任务/敌人数据应存储在 JSON/CSV，通过 Database 类加载，保持代码整洁
