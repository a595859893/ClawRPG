# REQ-096 Integration Test — 游戏内命令控制台

## 手动测试步骤

1. 启动游戏，进入战斗场景
2. 按 `` ` `` 键打开控制台，确认输入框出现
3. 输入 `/help`，确认显示命令列表
4. 输入 `/godmode`，受击不掉血（无敌状态开启）
5. 输入 `/spawn goblin 3`，确认屏幕上出现3只哥布林
6. 输入 `/kill_all`，确认哥布林全部消失
7. 上下键翻历史，确认能调出之前命令
8. 再次执行 `/godmode`，确认无敌关闭（受击掉血）
9. 输入 `/gold abc`，确认显示参数错误提示而非崩溃
10. 关闭游戏重新打开，确认历史命令已持久化保留

## 验收标准

- [x] `` ` `` 键打开/关闭控制台
- [x] `/help` 显示命令列表
- [x] `/spawn <entity> [count]` 生成实体
- [x] `/godmode` 开关无敌
- [x] `/gold <amount>` 增加金币
- [x] `/kill_all` 击杀所有敌人
- [x] 上下键翻历史
- [x] 历史最多50条（FIFO）
- [x] 非 DEBUG 模式按 `` ` `` 无反应
- [x] 错误参数有友好提示

## 风险记录

- 命令执行必须在主线程（战斗期间调用）
- RELEASE 编译下控制台完全不可用
